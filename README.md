## 🚀 About Me

I am a software engineer specializing in **Generative AI Engineering, Autonomous Agent Systems, and Graph-Native Memory Architectures**. I build production-grade web systems and AI applications where agents have grounded context, explainable decision-making, and zero-hallucination memory pipelines.

- 🧠 **Current Focus:** Graph-grounded agent memory (FalkorDB), multi-agent coordination, and deterministic knowledge firewalls.
- 🛠️ **Full-Stack Craft:** Next.js 16, TypeScript, Tailwind CSS v4, FastAPI, and Supabase.
- 🎓 **Background:** Mechanical & Mechatronics Engineering foundation paired with Stanford's Code in Place.
- 🎯 **Mission:** Bridging the gap between raw LLM intelligence and reliable, verifiable real-world applications.
